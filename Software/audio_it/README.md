# Voice recordings

WAV recordings from the prototype are not included pending redistribution-rights review. Runtime expects mono 16 kHz PCM WAV fragments with names matching `tools/generate_italian_audio.py`, including reset, shutdown, auto_on and auto_off.

The existing macOS helper uses the Alice system voice. Its inclusion is not a grant of rights to redistribute generated audio. A distribution-compatible voice pack must be selected before public release.
