# Enclosure

The builder designed and printed a custom enclosure that mounts to the OWON XDM1041 using its existing rear holes.

## Original design files

- [Autodesk Fusion — LogiVOX.f3d](../3D/AutodeskFusion/LogiVOX.f3d)
- [Bambu Studio — LogiVOX.3mf](../3D/BambuStudio/LogiVOX.3mf)

These files were supplied by the builder and copied unchanged. Archive integrity was checked, but the models have not yet been opened or print settings validated in their respective applications.

STEP/STL exports, material, printer settings and assembly instructions are still pending. Photographs and video are available in [Foto_Video](../Foto_Video/README.md).
